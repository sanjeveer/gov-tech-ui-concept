# AI-Powered Multilingual Voice Interactive Gov Portal Concept

A concept portal designed to make government services accessible via voice commands in multiple languages.

## 🚀 Live Demo
[View Live Project](https://sanjeveer.github.io/gov-tech-ui-concept/)

## ✨ Features
- Multilingual voice support using Web Speech API
- AI response generation integrated via API
- Accessible UI layout for civic access

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- GitHub Pages
